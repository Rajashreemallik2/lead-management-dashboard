# Lead Management Dashboard

## Overview
This is a mini CRM-style dashboard built as part of an internship assignment.  
It allows management of leads with features like:

- Login page (demo credentials)
- Leads table with **pagination** and **search**
- Analytics cards showing:
  - Total leads
  - Converted leads
  - Leads by status
- Fully responsive frontend
- Connected to MongoDB backend

---

## Technologies Used
- **Frontend:** React (Vite)
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas (free tier)
- **Deployment:** Vercel (frontend) + Render (backend)
